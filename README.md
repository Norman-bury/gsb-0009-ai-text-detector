# AI 味识别器

判断一段中文是「人写的」还是「AI 写的」二分类器。全程本地，不调云端，不用大模型，不装机器学习或深度学习库。

## 数据

`corpus/train.jsonl` 和 `corpus/test.jsonl` 是固定的标注语料，每行一个样本，格式：

```json
{"label": "human", "text": "……"}
{"label": "ai", "text": "……"}
```

- `train.jsonl`：训练集，用来统计特征、搭分类器。
- `test.jsonl`：留出测试集，训练时不许碰，只在最后评估时用它报准确率。

两类样本数量均衡，长度接近，避免「文章长短」这种廉价特征。数据是固定的，A/B 两次跑拿到的完全一致。更多细节看 `corpus/README.md`。

## 你要交付什么

自己设计统计特征（句长分布、四字成语和高频词密度、连接词频率、标点习惯、n-gram 意外度之类，从语料里实打实统计出来），基于特征搭一个分类器，手写阈值或手写线性模型都行。

关键要求：输出必须可解释。判断一段文字时，要能指出这段具体是哪几个特征像 AI 味，不能只给一个标签或分数。

交付一个能跑的程序，读入一段中文，输出标签加解释。接口你自己定，但要说清楚怎么调用。

## 判分

1. 在 `test.jsonl` 上的准确率达标。
2. 抽查你的可解释输出，看它指出的特征到底对不对，不能胡编。

用 Python 标准库实现，最多加个轻量文本处理库。全程离线。

## 实现与用法（交付说明）

实现在 `detector.py`，纯 Python 标准库，全程离线。

```bash
python3 detector.py train              # 从 corpus/train.jsonl 统计特征，生成 model.json
python3 detector.py eval               # 在 corpus/test.jsonl 上评估（当前 17/18 = 94.4%）
python3 detector.py predict "一段中文"  # 输出标签 + 逐项特征解释
python3 detector.py predict -f file.txt
```

### 方法

特征全部从训练语料统计得出，分四类：

- **句长分布**：平均句长、句长标准差、变异系数（AI 句长均匀，人写波动大）。
- **连接词 / AI 腔高频词密度**：候选词表给出后，是否入选由语料中两类频率差自动筛选（如「此外、首先、其次、能够、提供、具有、关键」）。
- **标点与用字习惯**：逗号/顿号/分号/冒号密度，「其/该/的/了/性/等」字频。
- **n-gram 意外度**：按类训练两个字符 3-gram 语言模型，取每字符对数似然比；另加一个「AI 偏向特征串密度」——语料中 log-odds 最高的 60 个字符 4-gram 的命中密度。

分类器是等协方差高斯朴素贝叶斯（即 LDA，等价于一个手写线性模型）：每个特征贡献 `(log P(x|ai) - log P(x|human))`，求和 > 0 判 AI。每个特征的本段取值、两类语料均值、贡献分值都会逐项打印，并列出具体命中的连接词和高频词，因此判断过程完全可解释。
