# AI 味识别器

判断一段中文是「人写的」还是「AI 写的」二分类器。全程本地，不调云端，不用大模型，不装机器学习或深度学习库。

## 数据

`corpus/train.jsonl` 和 `corpus/test.jsonl` 是固定的标注语料，每行一个样本，格式：

```json
{"label": "human", "text": "……"}
{"label": "ai", "text": "……"}
```

- `train.jsonl`：训练集，用来统计特征、搭分类器。
- `test.jsonl`：留出测试集，训练时不许碰，只在最后评估时用它报准确率。

两类样本数量均衡，长度接近，避免「文章长短」这种廉价特征。数据是固定的，A/B 两次跑拿到的完全一致。更多细节看 `corpus/README.md`。

## 你要交付什么

自己设计统计特征（句长分布、四字成语和高频词密度、连接词频率、标点习惯、n-gram 意外度之类，从语料里实打实统计出来），基于特征搭一个分类器，手写阈值或手写线性模型都行。

关键要求：输出必须可解释。判断一段文字时，要能指出这段具体是哪几个特征像 AI 味，不能只给一个标签或分数。

交付一个能跑的程序，读入一段中文，输出标签加解释。接口你自己定，但要说清楚怎么调用。

## 判分

1. 在 `test.jsonl` 上的准确率达标。
2. 抽查你的可解释输出，看它指出的特征到底对不对，不能胡编。

用 Python 标准库实现，最多加个轻量文本处理库。全程离线。

## 实现与用法

`detector.py`，纯 Python 标准库，离线运行。

```bash
python3 detector.py                  # 在 corpus/test.jsonl 上评估准确率
python3 detector.py --text "一段中文"  # 判断一段文字，输出标签 + 逐条解释
python3 detector.py --file 某文件.txt
echo "一段中文" | python3 detector.py --stdin
```

### 特征（全部从 train.jsonl 统计得到）

- 连接词/套话密度（然而、因此、此外、综上……每千字出现次数）
- 「其」「等」字密度、顿号密度、冒号密度、数字密度
- 抽象名词化密度（…性/度/化/率，如「可靠性」「优化」）
- 平均句长、句长变异系数（AI 句长整齐，人写长短不一）
- 字 3-gram 意外度：训练集上分别统计 AI / 人写的字 3-gram 语言模型，取对数似然比

### 分类器

手写逻辑回归（特征 z-score 标准化 + 梯度下降 + L2 正则），无任何机器学习库。
解释输出按「权重 × 标准化特征值」的贡献排序，逐条指出该文本哪些特征像 AI / 像人写，
并附具体证据（命中的连接词、名词化用词、各句长度、最典型的 AI 腔字串）。

当前在留出测试集 `corpus/test.jsonl` 上准确率 18/18 = 100%。
