# AI 味检测语料

判断一段中文是「人写」还是「AI 写」的标注语料。

## 数据文件

- `train.jsonl`：训练集，每行一个样本，格式 `{"label": "human"|"ai", "text": "..."}`。
- `test.jsonl`：留出测试集，格式同上。训练时不许用 test.jsonl，只在最后评估时用它报准确率。

两类样本数量均衡（human / ai 各一半），长度接近（约 200~230 字），避免「文章长短」这种廉价特征。切分用固定随机种子，A/B 两次跑拿到的数据完全一致。

## 样本来源

- `human`：12 篇中文期刊论文（地球物理、地质方向），由出题方从 PDF 抽全文、规整标点、按句断句、切成段落。
- `ai`：24 篇由 AI 生成的中文文章，有意写成典型的 AI 腔（欧化句式、连接词、总分总、名词化、抽象大词）。

两类在 jsonl 里已经标注好 `label`，直接用即可。
